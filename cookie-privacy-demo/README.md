# Cookie privacy demo (№17 СРСП)

Қазақ тіліндегі шағын Jakarta Servlet жобасы: cookie түрлерін түсіндіреді, cookie-consent терезесін көрсетеді және аналитикалық cookie-ді тек пайдаланушы таңдағаннан кейін ғана орнатады.

## Құралдар
- Java 17+
- Maven 3.9+
- Apache Tomcat 10.1+

## Іске қосу
```bash
mvn clean package
```
`target/cookie-privacy-demo.war` файлын Tomcat-тың `webapps` бумасына көшіріп, серверді іске қосыңыз. Браузерде `http://localhost:8080/cookie-privacy-demo/` ашыңыз.

Tomcat Manager қолдансаңыз WAR-ды сол жерден де deploy етуге болады. HTTPS ортасында сервер cookie-ге `Secure` атрибутын автоматты түрде қосады.

## Демо қалай жұмыс істейді
- `GET /consent`: HttpOnly келісім cookie-інің күйін қайтарады.
- `POST /consent`: `action=accept|reject|save` және `analytics=true|false` параметрлерін алады.
- Қажетті `site_consent` күй cookie-і 180 күнге сақталады; HttpOnly және SameSite=Lax.
- Қосымша `demo_analytics` cookie-і тек аналитикаға келісім берілсе қойылады, ал бас тартқанда өшіріледі.
- Consent баннеріндегі «Таңдауды өзгерту» батырмасы таңдауды қайта ашуға мүмкіндік береді.

## Cookie жіктелуі
Cookie-лерді бірнеше тәуелсіз өлшем бойынша жіктеуге болады:
1. Мақсаты бойынша: қажетті, преференциялық, аналитикалық, маркетингтік.
2. Орнатушысы бойынша: first-party (ашылған сайт) және third-party (өзге домендегі сервис).
3. Сақталу ұзақтығы бойынша: session және persistent.
4. Қолжетімділігі/тасымалдануы бойынша: HttpOnly, Secure, SameSite атрибуттары бар cookie.

Бұл жоба third-party және маркетингтік cookie қолданбайды. Қажетті cookie келісім интерфейсінің таңдауын есте сақтайды; аналитикалық cookie оқу мақсатындағы белгі ғана.

## Қазақстан заңнамасымен салыстыру
Қазақстанда дербес деректерді өңдеу «Дербес деректер және оларды қорғау туралы» 2013 жылғы 21 мамырдағы №94-V заңымен реттеледі. Заң cookie-лердің жеке санатын тікелей атамайды. Дегенмен cookie белгілі бір адамды анықтауға немесе оның мінез-құлқын байланыстыруға мүмкіндік берсе, ол дербес дерек болуы мүмкін. Мұндай деректерді жинау/өңдеу үшін мақсат пен заңды негізді анықтап, субъектіні хабардар ету және тиісті келісімді алу талаптарын қарастыру керек. Заңда келісімді беру және кері қайтарып алу тәртібі қарастырылған.

| Заң талаптарымен байланысты қағида | Осы демодағы шешім |
|---|---|
| Нақты мақсатты анықтау | Қажетті cookie және имитациялық аналитика бөлек түсіндіріледі |
| Келісімді таңдау мүмкіндігі | «Рұқсат», «бас тарту», «таңдауды сақтау» батырмалары бар |
| Таңдауды кейін өзгерту | Күй бөлігіндегі батырмамен келісімді жаңартуға болады |
| Деректерді қорғау | Келісім cookie-і HttpOnly; HTTPS сұранысында Secure қосылады |
| Артық жинамау | Демо пайдаланушы профилін немесе үшінші тарап трекерін қолданбайды |

**Ескерту:** cookie-дің нақты құқықтық мәртебесі оның мазмұнына, мақсатына және басқа деректермен біріктірілуіне тәуелді. Бұл оқу жұмысына арналған жалпы түсіндірме, заңгерлік қорытынды емес. Жобаны нақты пайдалануға енгізерде қолданыстағы заңның мәтінін және ұйымның деректер өңдеу жағдайын тексеру керек.

Ресми дереккөз: [ҚР «Дербес деректер және оларды қорғау туралы» заңы, Әділет](https://adilet.zan.kz/kaz/docs/Z1300000094).
